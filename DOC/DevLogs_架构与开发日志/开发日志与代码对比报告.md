### 2.2 惰性枯萎状态机

#### 日志描述
```
VIBRANT: 最后专注 < 24小时
WARNING: 最后专注 24-48小时
WITHERED: 最后专注 > 48小时
```

#### 代码实现 (GardenViewModel.kt)
```kotlin
enum class GardenVitalityState {
    VIBRANT { ... },
    WARNING { ... },
    WITHERED { ... };

    companion object {
        const val VIBRANT_THRESHOLD_MS = 24 * 60 * 60 * 1000L
        const val WARNING_THRESHOLD_MS = 48 * 60 * 60 * 1000L

        fun fromTimeDiff(lastFocusTimeMs: Long, currentTimeMs: Long): GardenVitalityState {
            val diff = currentTimeMs - lastFocusTimeMs
            return when {
                diff < VIBRANT_THRESHOLD_MS -> VIBRANT
                diff < WARNING_THRESHOLD_MS -> WARNING
                else -> WITHERED
            }
        }
    }
}
```

#### 验证结论
| 项目 | 日志 | 代码 | 一致性 |
|-----|-----|-----|--------|
| 状态数量 | 3种 | 3种 | ✅ |
| VIBRANT阈值 | <24h | <24h | ✅ |
| WARNING阈值 | 24-48h | 24-48h | ✅ |
| WITHERED阈值 | >48h | >48h | ✅ |
| 视觉效果 | 饱和度/亮度变化 | saturationMultiplier/brightnessMultiplier | ✅ |


#### 代码实现 (FocusRepository.kt)
```kotlin
suspend fun saveFocusRecord(...): FocusRecordEntity {
    val record = FocusRecordEntity(
        recordId = recordId,
        userId = userId,
        taskName = taskName,
        durationMinutes = durationMinutes,
        startTime = startTime,
        syncStatus = 0,  // 未同步
        signature = signature,
        rewardSettled = 0
    )
    focusRecordDao.insertRecord(record)
    return record
}
```
