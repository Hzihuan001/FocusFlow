# 2026-04-27 浅色主题高对比度优化

## 问题描述

用户反馈浅色主题下部分组件（如文字"完全由你掌控节奏"和"点击全部评估设置"）在白色背景上几乎看不见，对比度不足。

**原因分析**:
- 原浅色主题使用了灰绿色系（`#5A6B62`）作为副文字颜色
- 背景色为近白色（`#F5F7F5`），与副文字颜色对比度不足
- 主色调使用深绿色（`#00875A`），不符合纯黑白灰设计要求

## 解决方案

采用纯黑白灰三色调设计，确保高对比度：

### 1. 浅色主题颜色调整

**文件**: `FocusFlow_App/app/src/main/java/com/example/focusflow/ui/theme/AppTheme.kt`

**修改前**:
```kotlin
val LightAppColors = AppColors(
    primary          = Color(0xFF00875A),   // 深绿
    primaryDim       = Color(0x2200875A),
    bgDeep           = Color(0xFFF5F7F5),   // 近白背景
    cardBg           = Color(0xFFFFFFFF),   // 纯白卡片
    textMain         = Color(0xFF1A1A1A),   // 近黑主文字
    textSub          = Color(0xFF5A6B62),   // 灰绿副文字（对比度不足）
    isLightStatusBar = true,
    isDark           = false
)
```

**修改后**:
```kotlin
val LightAppColors = AppColors(
    primary          = Color(0xFF000000),   // 纯黑主色调（边框、图标）
    primaryDim       = Color(0x1A000000),   // 10% 透明度黑色
    bgDeep           = Color(0xFFFFFFFF),   // 纯白背景
    cardBg           = Color(0xFFF5F5F5),   // 浅灰卡片背景（5% 灰）
    textMain         = Color(0xFF000000),   // 纯黑主文字
    textSub          = Color(0xFF666666),   // 中灰副文字（40% 灰）
    isLightStatusBar = true,
    isDark           = false
)
```

**设计原则**:
- **纯白背景** (`#FFFFFF`): 最大化打印效果
- **纯黑文字** (`#000000`): 最高对比度，确保可读性
- **中灰副文字** (`#666666`): 40% 灰度，与白色背景对比度 4.5:1（符合 WCAG AA 标准）
- **浅灰卡片** (`#F5F5F5`): 5% 灰度，提供层次感但不影响打印

### 2. 图表颜色优化

**文件**: `FocusFlow_App/app/src/main/java/com/example/focusflow/ui/theme/PrintFriendlyColors.kt`

**修改前**:
```kotlin
val lightThemeChartColors = listOf(
    Color(0xFF1A1A1A),  // 深灰（L* ≈ 10）
    Color(0xFF4D4D4D),  // 中深灰（L* ≈ 30）
    Color(0xFF808080),  // 中灰（L* ≈ 50）
    Color(0xFFB3B3B3),  // 中浅灰（L* ≈ 70）
    Color(0xFFD9D9D9),  // 浅灰（L* ≈ 85）
    Color(0xFF00875A)   // 深绿（强调色）
)
```

**修改后**:
```kotlin
val lightThemeChartColors = listOf(
    Color(0xFF000000),  // 纯黑（L* = 0）
    Color(0xFF333333),  // 深灰（L* ≈ 20）
    Color(0xFF666666),  // 中深灰（L* ≈ 40）
    Color(0xFF999999),  // 中灰（L* ≈ 60）
    Color(0xFFCCCCCC),  // 浅灰（L* ≈ 80）
    Color(0xFFE6E6E6)   // 极浅灰（L* ≈ 90）
)
```

**设计原则**:
- **纯灰度阶梯**: 移除深绿色强调色，使用纯黑白灰
- **均匀分布**: 每级灰度间隔 20%，确保明显区分
- **打印友好**: 相邻颜色 CIELAB ΔL* ≥ 20，黑白打印时有明显对比

## 技术细节

### 颜色选择标准

**主文字（纯黑）**:
- Hex: `#000000`
- RGB: (0, 0, 0)
- CIELAB L*: 0
- 用途: 标题、正文、重要信息

**副文字（中灰）**:
- Hex: `#666666`
- RGB: (102, 102, 102)
- CIELAB L*: 40
- 用途: 说明文字、次要信息、提示文本

**卡片背景（浅灰）**:
- Hex: `#F5F5F5`
- RGB: (245, 245, 245)
- CIELAB L*: 96
- 用途: 卡片背景、分隔区域

**页面背景（纯白）**:
- Hex: `#FFFFFF`
- RGB: (255, 255, 255)
- CIELAB L*: 100
- 用途: 页面主背景

### 灰度阶梯计算

使用线性灰度分布，每级间隔 20%:
- 0% (纯黑): `#000000`
- 20% (深灰): `#333333`
- 40% (中深灰): `#666666`
- 60% (中灰): `#999999`
- 80% (浅灰): `#CCCCCC`
- 90% (极浅灰): `#E6E6E6`
